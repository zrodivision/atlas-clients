# Atlas hosted connector

Install this plugin through your harness plugin manager and complete its native browser OAuth. The connector URL is https://connectatlas.io/mcp. Browser app: https://connectatlas.io/app. Keep the service origin separate from the browser path. No Atlas source checkout or CLI is required.

Sign in or sign up, name your Atlas account, and approve an existing line or create an independent one. Surfaces of the same harness can share a line and its grants; each connection has its own credentials. Vault access and contact exposure remain explicit owner decisions.

In a fresh chat, read atlas://me to verify account and line, then use atlas_console where MCP Apps are supported. Installing configuration alone does not establish authentication. Disconnect individual connections in Atlas Console.

This native-only source candidate includes workflow guidance and generated tool references. Cellular calls and SMS are outside the production path. Computer workers remain a source candidate, not a deployed service. The Atlas service owns data and authorization. Never put tokens in plugin files. Release candidate 0.14.2-rc.1: package generation does not establish deployment or native-host acceptance.
